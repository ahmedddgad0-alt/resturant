MAISON NOIR — Premium Restaurant Website
==========================================

تشغيل المشروع:
1. فك ضغط الملف.
2. افتح index.html في Chrome أو Edge.
3. لا يحتاج إلى تثبيت أو خادم لتجربة الواجهة.

الملفات:
- index.html: الصفحة الرئيسية ومحتوى الموقع.
- style.css: الهوية البصرية والتصميم المتجاوب.
- script.js: القائمة، تصفية الأطباق، إشعارات الاختيار، ونموذج الحجز.

قبل تسليم المشروع:
- استبدل رقم واتساب التجريبي 201000000000 في script.js برقم المطعم بصيغة دولية بدون +.
- عدّل العنوان وساعات العمل والأسعار والأطباق.
- استبدل التقييم التجريبي بتقييم حقيقي أو احذف القسم.
- الصور والخطوط مستضافة خارجياً (Unsplash وGoogle Fonts)، لذلك تحتاج اتصال إنترنت.
- نموذج الحجز يجهز رسالة واتساب فقط؛ لا يوجد نظام قاعدة بيانات أو لوحة إدارة.
- الأسعار واسم المطعم والبيانات أمثلة تصميمية وليست بيانات نشاط حقيقي.
